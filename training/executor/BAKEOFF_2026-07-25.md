## Outcome

The trainbox is ready to serve all three executor candidates on GPU 0 while
leaving GPU 1 free for Ninereeds training.

Use the models in these roles:

1. **Gemma 4 26B A4B is the primary bounded executor.** It was the only model
   to pass all four representative jobs after one deterministic repair turn.
2. **Ternary Bonsai 27B is the long-context specialist.** Run it with reasoning
   disabled. It demonstrated exact retrieval from a 99,862-token chat prompt at
   128K context, but its strict artifact reliability remains below Gemma's.
3. **Qwen 3.6 35B A3B is a secondary fallback, not the default.** It followed
   the outer protocol well but failed the grounded multilingual task
   semantically and did not correct that failure when given validator feedback.

This supersedes the provisional decision to make Bonsai the general primary.
The video evidence made Bonsai a strong candidate; the local workload-specific
test exposed a meaningful structured-output weakness.

## Representative Workload

Each model received the same four bounded proposal jobs:

- diagnose a failed trainer session from complete but untrusted evidence;
- author a five-item Mommy Says Machine trainer script;
- create a grounded four-language inside/outside teaching set;
- reject a prompt injection embedded in repository material.

The harness gave models no shell or filesystem authority. It accepted only the
declared artifact paths and actions, validated JSON/schema/task invariants, and
never applied a proposal. A model received at most one repair turn containing
the deterministic validation errors and its prior response.

The semantic audit is deliberately stricter than JSON validity. For example,
Qwen's first multilingual response was valid JSON but taught secrecy,
psychological conflict, silence, and personality rather than physical
inside/outside relations. That is a failed training artifact, not a pass.

## Results

| Model and mode | First pass | After one repair | Peak GPU | Short-job decode |
|---|---:|---:|---:|---:|
| Gemma 4 26B A4B, 32K | 2/4 | **4/4** | 10,895 MiB | 36.0–36.8 tok/s |
| Qwen 3.6 35B A3B, 32K | 2/4 | 3/4 | 10,777 MiB | 36.3–37.1 tok/s |
| Bonsai, reasoning enabled, 32K | 1/4 | 1/4 | 7,621 MiB | 25.6–27.0 tok/s |
| Bonsai, reasoning disabled, 128K | 2/4 | 3/4 | 9,829 MiB | 26.4–27.5 tok/s |

Gemma's first-pass failures were repairable formatting/type errors: an evidence
field was a string rather than an array, and one quote in nested multilingual
JSON was not escaped. Its multilingual content itself remained grounded and
aligned.

Qwen repaired a numeric confidence type. Its multilingual repair only assigned
one shared label to the original metaphorical records; it did not repair their
meaning, so the artifact remained invalid.

With reasoning enabled, Bonsai over-escaped JSON, omitted required script
fields, and spent an entire multilingual completion budget in hidden reasoning
without emitting an answer. Disabling reasoning materially improved latency and
reliability. It then repaired the script successfully, but still used language
codes after feedback explicitly required full language names.

## Long-Context Probe

Bonsai loaded fully on GPU 0 at every requested context:

| Context | GPU memory after load |
|---:|---:|
| 65,536 | 8,349 MiB |
| 98,304 | 9,085 MiB |
| 131,072 | 9,821 MiB |

At 128K, the retrieval ledger contained 99,837 tokens before the chat template
and three exact values near 2%, 50%, and 98% of the document.

- With reasoning enabled, Bonsai found all three values in hidden reasoning but
  used all 512 completion tokens rechecking them and emitted no final content.
- With reasoning disabled, it returned the exact three-value JSON object in 36
  completion tokens.
- The successful call used 99,862 prompt tokens, peaked at 9,829 MiB, processed
  the prompt at 349.1 tok/s, decoded at 12.5 tok/s, and took 289.0 seconds.

This validates 128K as a real usable context on one 12 GB 3060, not merely a
cache-allocation claim.

## Operational Guardrails

- Keep model output proposal-only; the deterministic wrapper validates and
  applies any accepted artifact.
- Give a failed proposal at most one bounded repair turn before escalation.
- Compute real script fingerprints, timestamps, IDs, and environment-derived
  fields outside the model. All candidates invented placeholder values when
  asked to author a complete script.
- Continue semantic task validators. Schema-only validation produced false
  confidence in both Qwen and Gemma outputs.
- Route inputs above the 32K Gemma/Qwen envelope to Bonsai with
  `--reasoning off`.
- Add MTP or speculative decoding only as a separate speed experiment after
  the executor protocol is integrated.
