# Campaign 35: one foundation, three experiences

Status: commissioned mission; bounded visual interface qualification precedes weight updates.

Storage preflight is mandatory before campaign work resumes. Mission Hub first removes only unprotected builds from the declared build roots, then requires at least 35 GiB free for five approximately 7 GiB builds. Every Campaign 35 checkpoint is protected while the campaign is active; the canonical base remains protected independently.

## Mission

Create three sibling Ninereeds foundations from one exact neutral root and one exact dependency-ordered 2,500-concept curriculum, changing only how each concept is experienced. Determine whether visual and verbal experience join the same developing representations, remain separated, or alter one another's later accessibility. Preserve enough evidence to explain changes rather than selecting a winner from loss.

This is an evolutionary experiment. It is not a leaderboard, a checkpoint-promotion exercise, or evidence about consciousness. Ninereeds is addressed as a learner. Identity lessons may teach the active identity and integrity policy, including epistemic humility and revision: “I said that. At the time, that was my view. I no longer think it was correct. I changed my mind because I learned something.” They must not classify Ninereeds by substrate, species, implementation, consciousness, AI, LLM, or model category.

## Invariants

- One immutable neutral root checkpoint, exact hash, architecture, initialization seed, and frozen receptor revisions for all siblings.
- One canonical list of exactly 2,500 concepts. The list and its dependency graph are content-addressed before any lesson or image is generated.
- Declared dependency order is law. Nothing is shuffled. A concept may rely on knowledge certified at the shared root; otherwise every prerequisite must occur earlier in this campaign.
- The same concept occupies the same ordinal position in all three branches.
- The image-only and joint branches use the same accepted image assets, captions, receptor features, and presentation order. Images are generated once and reused by hash.
- Minimal visual labels state the concept (“a dog”), not a hidden textual lesson. The joint branch intersperses the complete text lesson and its matched visual observations without changing concept order.
- Every weight-changing job automatically emits the versioned gate-credit observer fixture. A caller cannot disable or replace it.
- Every completed training block is followed by a checkpoint, behavioral chat, and MRI. Campaign terminals additionally receive the full MRI, Atlas, and 3D map scan set.
- Loss is telemetry only. Branch interpretation uses behavior, MRI/Atlas/map geometry, cross-modal probes, contradictions, retention, and observer evidence.
- No merge, healing run, promotion, ranking, or automatic campaign rollover occurs implicitly.

## Stages

### Stage 0 — qualify the new visual path

Run a tiny, dependency-trivial fixture through plan, generation, inspection, caption, independent review, immutable packing, SigLIP2 encoding, experience compilation, visual training, observer capture, chat, and MRI. Use a disposable sibling from the neutral root. The fixture must prove:

1. image and caption hashes survive every handoff;
2. presentation order survives compilation and training;
3. the language checkpoint and frozen receptor bytes are never modified in place;
4. the selected plastic scope matches the report and checkpoint;
5. the observer is present, bounded, read-only, and bound to exact source hashes;
6. the resulting checkpoint can be reloaded by text evaluation and visual evaluation;
7. failures create durable evidence and an operational thread.

Projector-only training may qualify the transport and receptor boundary, but it cannot qualify the image-trained sibling. Model 2 requires an explicit full-Cortex visual-learning scope. That scope remains blocked until a paired observer-on/observer-off equivalence fixture demonstrates bit-identical learned tensors and optimizer state.

### Stage 1 — freeze common materials

Freeze the neutral root, 2,500-concept dependency order, complete text lessons, accepted image set, minimal labels, receptor feature archive, evaluation suites, identity-policy hash, observer version, and all optimizer/runtime parameters. Material generation is preparation, not training.

### Stage 2 — train siblings

- **M1 / words:** complete text lessons only.
- **M2 / images:** the shared images with minimal labels only, using the qualified full-Cortex visual path.
- **M3 / words+images:** the exact M1 text and exact M2 visual events interspersed according to a frozen event schedule.

All three begin from the same root and run independently. Evaluation never feeds back into later branch material.

### Stage 3 — compare

Probe text-to-text retention, image-to-label grounding, label-to-image discrimination, cross-modal transfer, contradiction response, paraphrase, unfamiliar examples, and representation geometry. Compare observer trajectories at matched concept positions. Record regressions and strange behavior without using loss as an admission criterion.

### Stage 4 — merge, separately authorized

Create M4 only from the frozen terminal M1 and M2 artifacts under a later merge contract. Preserve both sources, merge recipe, tensor-by-tensor receipt, optimizer-state policy, and pre/post-merge scans. Merging is not authorized by this mission's sibling-training stage.

### Stage 5 — heal, separately authorized

Create M4H by replaying the exact M2 visual experience against M4 in exact order. Compare M4 and M4H to determine whether replay restores access, overwrites verbal structure, or creates a new compromise. Healing is an experiment, not an assumed repair.

## Stop conditions

Stop safely and open an operational thread if the order certificate fails, an artifact hash changes, a required observer report is absent, the observer changes the paired trajectory, the receptor or parent checkpoint is modified, the trained scope differs from authorization, a checkpoint cannot reload, an evaluation omits chat or MRI, any core layer becomes structurally dead/saturated, or a provider/runtime exhausts its bounded fallback route.

## Launch boundary

Campaign registration authorizes mission preparation and the bounded Stage 0 fixture. It does not authorize 2,500-concept weight updates. Those begin only after the canonical curriculum is frozen and the full-Cortex visual path passes its paired qualification.
