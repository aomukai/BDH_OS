POINT: agreeing with a preceding clause using `so / neither / nor + auxiliary`
DIFFICULTY: 4
TOPIC: needs, wants, and preferences
GROUNDING: TEXT
VOCAB_SET_1: like, love, prefer, dislike
VOCAB_SET_2: need, want, enjoy, hate
VOCAB_SET_3: opera, ballet, jazz, rock
PPP:
- AFFIRMATIVE: `Maya likes the opera. Does Leo like it too? — Yes; so does Leo.`
- NEGATIVE: `Maya doesn't like ballet. Does Leo like it? — No; neither does Leo.`
- W-QUESTION: `Who else likes the opera? — Maya likes it, and so does Leo.`
- OR-QUESTION: `Does Leo like the opera or ballet? — He likes the opera, and so does Maya; he doesn't like ballet, and neither does Maya.`
