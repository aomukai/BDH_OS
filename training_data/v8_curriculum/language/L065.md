PPP:
- AFFIRMATIVE: `The library is open, isn't it? — Yes, the library is open.`
- NEGATIVE: `The library is closed, isn't it? — No, the library isn't closed.`
- W-QUESTION: `The library closes at six. How can you check that? — The library closes at six, doesn't it?`
- OR-QUESTION: `You think the library is open. Do you say “It's open, isn't it?” or “It isn't open, is it?” — “It's open, isn't it?”`
