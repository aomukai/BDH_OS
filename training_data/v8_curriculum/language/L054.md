POINT: using the conventional activity pattern `go for a + noun`
DIFFICULTY: 2
TOPIC: outdoor leisure activities
GROUNDING: IMAGE

- NEGATIVE: `Did Ken go for a swim? — No, Ken didn't go for a swim.`
