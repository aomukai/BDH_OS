lesson L120
POINT: identifying a referent with a defining relative clause using `that`
DIFFICULTY: 3
TOPIC: input and output devices
GROUNDING: IMAGE
VOCAB_SET_1: keyboard, mouse, scanner, microphone
VOCAB_SET_2: monitor, printer, speaker, projector
VOCAB_SET_3: tablet, screen, camera, drive
PPP:
- AFFIRMATIVE: `Is this the tablet that has the map? — Yes, this is the tablet that has the map.`
- NEGATIVE: `Is this the tablet that has the schedule? — No, this isn't the tablet that has the schedule.`
- W-QUESTION: `Which tablet is this? — This is the tablet that has the map.`
- OR-QUESTION: `Is this the tablet that has the map or the one that has the schedule? — It is the tablet that has the map.`
